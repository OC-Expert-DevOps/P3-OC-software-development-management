1 / Contexte fonctionnel

📋 Problématique métier

Problèmes identifiés

  • Freelances envoient des fichiers par email / WeTransfer
  • Aucun contrôle sur les liens partagés
  • Pas de traçabilité des téléchargements
  • Dépendance services cloud tiers payants
  • Risques confidentialité (données sensibles)

Solution DataShare

  • Upload sécurisé (auth JWT)
  • Liens temporaires + mot de passe
  • Historique complet des téléchargements
  • Self-hosted (Docker Compose)
  • Open source, auditeable, maîtrisé

ProblèmeCause racineSolution

BigInt JSON crash Prisma retourne BigInt, JSON.stringify crashe Override BigInt.prototype.toJSON
JWT userId null Guard mappait mal payload.sub Fix mapping sub → request.user.userId
